2. **Study interactively.** Start Học với AI on that set in Socratic mode. Explain a first guess, receive one focused question, then request a hint. Show Ask for a concise answer and Solve for numbered teaching steps/principles plus a comprehension check. Ask about one step; show cancellation/retry with no duplicate saved learner message.
3. **Approve knowledge.** Finish the session and extract candidate concepts. They are pending, with literal source provenance and no invented semantic similarity percentage. Edit a concept and explicitly approve it. Generate a single card; regenerating updates it rather than creating duplicates.
4. **Review before grading.** Start Ôn tập, try recalling the answer, reveal it, then choose Good. Show the next due instant and actual review evidence. A repeated/stale grade does not produce another event.
5. **Explain and recall.** In Tự kiểm tra, select approved concepts for Feynman, submit an explanation and inspect feedback linked to exact learner/source excerpts. Retry creates a distinct stored attempt. In Blurting, references stay hidden while composing; missing knowledge is separate from a quoted misconception. Insufficient references yield neutral feedback.
6. **Follow evidence.** Open Tiến bộ: statuses use actual review sample size and a documented deterministic heuristic, without fabricated mastery percentages. AI observations remain separate. Open a targeted study session for an area needing work.
7. **Reopen history.** Reload, search the saved session/concept and reopen an attempt/review. Explain that the reference snapshot preserves the historical assessment even after source edits. Profile/timezone and production counts come from real records.
